# OMJET Log Analyzer

Продвинутое десктопное приложение для анализа полётных логов ArduPilot (.bin, .log, .tlog).

## Возможности

- **Парсинг логов**: Поддержка форматов .bin (dataflash), .log (текст), .tlog (телеметрия)
- **Интерактивные карты**: Визуализация GPS-трека на спутниковой подложке Google (спутник/гибрид/карта/рельеф) с перетаскиваемым курсором
- **Дерево параметров с избранным и пресетами**: У каждого параметра есть звёздочка-переключатель — нажатие добавляет параметр в отдельную панель "Избранное" над общим списком (звёздочка становится жёлтой, параметр дублируется и остаётся доступным даже при пустом списке); набор избранного сохраняется на диске и восстанавливается между запусками, поле можно переименовать через правый клик → "Переименовать параметр", а весь список — очистить через "Очистить избранное"; ниже расположена панель "Пресеты" с готовыми наборами графиков (например, "AirSpeed - Ground Speed", "Battery 1 - Battery 2", "Baro - GPS Altitude" — сразу строят нужные кривые, в том числе с разбивкой по батарее); каждая ветвь дерева (ACC, ATT, BARO, BAT, GPS, IMU, RATE, RCIN, RCOU, EKF и др.) и каждое поле внутри неё снабжены русскоязычным описанием — отображается в третьей колонке и в подсказке при наведении
- **Мультиграфики**: До 3 синхронизированных графиков с несколькими кривыми; при добавлении двух и более параметров каждому автоматически назначается собственная вертикальная ось Y (независимое масштабирование — не мешает параметрам с разными единицами отображаться рядом); масштабирование колесом мыши по оси X и Y раздельно; кнопка 💾 у каждого графика сохраняет изображение в PNG/JPEG — файл включает строку со статистикой (min / max / mean) по всем кривым; кнопка ⛶ открывает график в отдельном полноэкранном окне с осью времени в формате мм:сс, hover-подписями значений при движении мыши, закреплёнными точками по клику (ПКМ — очистить) и кнопкой сохранения в PNG
- **Временная шкала**: Визуальный скрабер с отображением высоты; при наведении курсора на шкалу значок самолёта на карте перемещается в соответствующую точку трека, и наоборот — при наведении на трек карты курсор на шкале смещается синхронно
- **Режим воспроизведения**: Анимация пролёта лога с разной скоростью
- **Просмотр параметров**: Обзор и анализ полётных параметров
- **События**: Автоматическая расшифровка EV/ERR-сообщений (армирование, отказы подсистем и т.д.) на русском языке в таблице и в виде маркеров "!" на карте с подсказками при наведении, с переключателем видимости
- **Метки режимов и фотографий**: Цветные сегменты трека по режимам полёта, маркеры точек съёмки (CAM/TRIG) на карте со счётчиком и переключателем видимости
- **Геотегирование фотографий**: Отдельная вкладка с таблицей параметров каждого фотоснимка (координаты, высота AMSL/AGL, крен/тангаж/курс, путевая скорость, интервал и расстояние между кадрами) и экспортом в CSV — для построения ортофотоплана. Список фотографий загружается мгновенно в виде 5-колоночного списка имён (работает с 1000+ файлов без зависаний), миниатюры подгружаются в фоне и становятся доступны при переключении в режим "Миниатюры". Кнопка "Очистить фотографии" сбрасывает список. Поддерживается импорт точек привязки из внешнего файла GNSS-геометок (CSV/RTKLIB .pos); точки и фотографии можно исключать из геопривязки через контекстное меню; уже геотегированные снимки отмечаются значком-планетой с подсказкой координат/высоты; перед записью показывается окно предпросмотра соответствия "файл → координаты". Геотегированные копии сохраняются в подпапку **geotagged/** внутри папки с исходными фото — оригиналы не изменяются. При записи вносятся как стандартные **EXIF GPS**-теги, так и блок **XMP drone-dji** (GpsLatitude, GpsLongtitude, AbsoluteAltitude, RelativeAltitude) — для совместимости с Metashape, Pix4D и другими фотограмметрическими программами. Качество JPEG при перезаписи настраивается прямо в панели (без изменения / 95 / 85 / 75 / 65); двойной клик по фото открывает полноэкранный просмотр
- **Полётное задание (миссия)**: Вкладка разделена на две части — слева мини-карта с маршрутом и точками миссии (с переключателями "Центрировать" — автопанорамирование карты на выделенную точку — и "Показать весь трек" — авто-масштабирование на весь маршрут), справа таблица команд (Command, Lat, Lon, Alt, Frame, Params, Seq, Cmd ID, Description с переводом описания на русский), строки которой подсвечиваются по типу команды (взлёт/посадка VTOL — зелёным, начало фотосъёмки по дистанции — жёлтым, начало посадки — красным, облёт точки на высоте — оранжевым). Первая точка миссии (Home) обозначается «H» в колонке Сиквенс и оранжевым кружком в заголовке строки таблицы; на мини-карте маркер Home отображается оранжевым. Под картой справа отображается **протяжённость полётного задания** (сумма Haversine-расстояний между точками в км). При наведении на строку таблицы соответствующая точка подсвечивается на карте, и наоборот. Поддерживается экспорт миссии в формате QGC WPL 110 (.waypoints)
- **Анализ миссии**: Сводная статистика полёта в две колонки. Слева — группы "Время" (старт/финиш с часовым поясом UTC+X, длительность), "Полёт" (дистанция в метрах и км, время работы вертикальных и маршевого моторов, время планирования), "Скорости" (максимальная и средняя земная/воздушная скорость в горизонтальном полёте и за всю миссию; **максимальная вертикальная скорость набора и снижения** из CTUN.VSpd/NKF1.VD/GPS.VZ; рядом с максимальной земной скоростью отображается красный значок "!" с подсказкой «Значение может быть вычислено неверно», если эта скорость, удержанная более 2 секунд, превышает сумму максимальной воздушной скорости и максимального ветра за тот же критерий), "Ветер" (средний и максимальный ветер по данным EKF, преобладающее направление — встречный/боковой/попутный; кнопка **?** рядом со строкой направления открывает справку с классификацией ветра по углу между ветром и курсом ВС и формулами компонент встречной/боковой скорости), "Углы" (максимальные крен/тангаж) и "Фотосъёмка" (количество отправленных в камеры и полученных от камеры фотоимпульсов — метки CAM/TRIG, среднее время и расстояние между снимками). Справа — "Эффективность" (расход mAh на километр и на минуту, отдельно по всем моторам и только по маршевому, с цветными индикаторами по настраиваемым в Настройках порогам; цветной кружок напротив вертикальной тяги Q_M_THST_HOVER — зелёный/красный по настраиваемым порогам (по умолчанию 0.40/0.60); кнопка **?** рядом со значением открывает справку по параметру), "Качество радиосвязи" (средний SNR на борту и на земле, минимальный RSSI, максимальный уровень шума — по данным телеметрии RAD/RADIO; кнопка **?** в заголовке блока открывает справку с формулами расчёта SNR и таблицей ориентировочных значений качества связи) и статистика по каждой батарее (расход mAh, максимальный ток, удержанный не менее 2 секунд, и средний ток)
- **Отчёт о полёте (PDF + KML)**: Кнопка «Сформировать отчёт» во вкладке «Анализ миссии» открывает диалог настройки и создаёт PDF с картой трека на спутниковой подложке (первая страница сразу под заголовком), подробной статистикой полёта, а затем крупными планами взлёта и посадки на отдельных страницах; на каждой карте наносятся стрелка ветра с надписью **«Фактический ветер»** и средней скоростью за соответствующую фазу полёта (взлёт/посадка/весь маршрут), а в правом верхнем углу — крупный информационный блок с направлением ветра; точки фотосъёмки на карте — опционально; даты начала и конца миссии в формате ДД.ММ.ГГГГ ЧЧ:ММ:СС; одновременно создаётся KML-файл трека с корректной высотой над рельефом (BARO relative-to-home, режим relativeToGround) и маркерами фотографий для Google Earth / ГИС
- **Ветер**: Направление и скорость ветра (по данным EKF) отображаются красным треугольником на компасе панели ориентации; участки трека на карте, где скорость ветра превышает заданный порог, подсвечиваются белым свечением — флажок «Ветер» одновременно скрывает и панель в углу карты, и подсветку на треке; в панели «Допустимый ветер» ниже показателя максимального ветра расположен блок **«Текущий ветер»** — компасная стрелка направления ветра и текущая скорость в м/с, обновляются в реальном времени при движении курсора по шкале; сводная статистика по ветру и преобладающее направление доступны на вкладке "Анализ миссии"
- **Качество радиосвязи**: Отдельная вкладка с двумя Leaflet-картами на одном экране: левая — SNR на борту (RSSI − Noise), правая — SNR на земле (RemRSSI − RemNoise), данные берутся из сообщений RAD/RADIO телеметрии. Трек окрашивается градиентом от красного (слабый SNR) до зелёного (сильный SNR); толщина линии пропорциональна уровню RSSI (регулируется от 5 до 50 пикселей, по умолчанию 30). Пороги нормировки SNR (мин./макс.) выставляются прямо в панели управления вкладки — без перехода в Настройки; изменения синхронизируются с разделом Настройки и наоборот. Кнопка **?** рядом со шкалой открывает справку с формулами расчёта SNR и таблицей ориентировочных значений качества связи. Прозрачность регулируется ползунком; флажок «Во весь экран» убирает панель управления. Под картами — объединённый график SNR с двумя кривыми (борт/земля) с двунаправленным курсором карта↔график
- **Отображение RC**: Визуализация каналов управления
- **Панель ориентации**: Индикаторы крена/тангажа/рыскания, скорости, высоты и ветра, с цветовой индикацией силы тока и скорости по настраиваемым порогам; **вариометр вертикальной скорости** — заполняется от центра вверх (зелёный, набор) или вниз (красный, снижение); под авиагоризонтом отображается **тип борта** (VTOL 4+1, Квадрокоптер или Неизвестен), определяемый автоматически по конфигурации функций сервоканалов (SERVOx_FUNCTION) из лога
- **Монитор моторов/сервоприводов**: Визуализация PWM сигналов
- **Звуковые оповещения**: Опциональный звуковой сигнал по завершении загрузки лога (включается в Настройках)
- **Офлайн-кэш тайлов карты**: Загруженные тайлы спутниковой подложки сохраняются на диск и переиспользуются без повторной загрузки из сети; размер кэша и кнопка очистки доступны в Настройках
- **Настройки**: Тема (светлая/тёмная/системная), часовой пояс, язык, конфигурация батареи (количество ячеек, LiHV), цветовые пороги силы тока/скорости и максимальный ветер для подсветки на карте, пороги расхода mAh для индикаторов на вкладке "Анализ миссии", пороги вертикальной тяги Q_M_THST_HOVER, диапазон SNR для нормировки цвета трека (синхронизируется с панелью вкладки «Качество связи»), звуковые оповещения, управление кэшем тайлов карты; **блок «Статистика»** — накопительные счётчики: суммарное время работы с приложением (с точностью до минуты), количество открытых логов и геотегированных фотографий, сохраняются между сессиями; кнопка **«Проверить обновления»** сравнивает текущую версию с последним релизом на GitHub и предлагает перейти на страницу загрузки — при наличии интернета проверка также выполняется автоматически при каждом запуске приложения (в фоне, без блокировки интерфейса)
- **Тёмная/светлая тема**: Переключаемое оформление

## Установка

### Из релиза (Windows)
1. Скачайте последнюю версию `OMJET_Log_Analyzer.exe` со страницы [Releases](https://github.com/andrewkena/OMJET-LOG-Analayzer/releases)
2. Запустите исполняемый файл — установка не требуется

### Из исходников
```bash
# Клонировать репозиторий
git clone https://github.com/andrewkena/OMJET-LOG-Analayzer.git
cd OMJET-LOG-Analayzer

# Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate  # Windows
# source .venv/bin/activate  # Linux/Mac

# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python main.py
```

## Использование

1. Запустите приложение
2. Нажмите **Файл → Открыть лог...** или используйте Ctrl+O
3. Выберите файл лога ArduPilot (.bin, .log или .tlog)
4. Изучайте загруженные данные:
   - Используйте **Дерево сообщений** для выбора полей на график
   - Перейдите на вкладку **Графики** для просмотра выбранных параметров
   - Откройте вкладку **Карта** для визуализации GPS-трека
   - Проверьте вкладку **События** для отметок событий полёта
   - Откройте вкладку **Полетное задание** для просмотра маршрута миссии на карте и списка команд

### Управление графиками
- Отмечайте поля в дереве сообщений, чтобы добавить их на графики
- Выпадающий список выбирает целевой график (1, 2 или 3)
- Выделяйте диапазон на графике мышкой для выбора временного диапазона
- Используйте временную шкалу внизу для навигации по полёту

### Избранное и пресеты
- Нажмите на звёздочку рядом с параметром в дереве сообщений, чтобы добавить его в панель "Избранное" (звёздочка станет жёлтой); повторное нажатие убирает параметр из избранного
- Панель "Избранное" всегда отображается над общим списком параметров, даже когда она пуста
- Панель "Пресеты" ниже списка параметров содержит готовые комбинации графиков — выберите пункт, чтобы сразу построить нужные кривые (например, сравнение воздушной и земной скорости)

### Полетное задание
- Слева на карте отображается маршрут миссии с точками
- Справа — таблица команд миссии (Command, Lat, Lon, Alt, Frame, Params, Seq, Cmd ID, Description)
- Наведите курсор на строку таблицы, чтобы выделить соответствующую точку на карте, или на точку на карте, чтобы выделить её строку в таблице
- Кнопка **Download Mission (.waypoints)** экспортирует миссию в формате QGC WPL 110 для Mission Planner/QGroundControl

### Геотегирование фотографий
- Выберите папку с фотографиями — список появляется мгновенно (5 колонок), миниатюры подгружаются в фоне; переключатель "Миниатюры" показывает превью после загрузки
- Импортируйте файл точек привязки (**Открыть файл геометок GNSS...**, рядом с таблицей GNSS) — поддерживаются CSV и RTKLIB .pos; точки с аномальной высотой подсвечиваются красным
- Правый клик по точке GNSS или по фотографии — пункт "Исключить" удаляет её из геопривязки (строка и маркер на карте сереют)
- Выберите качество JPEG в выпадающем списке "Качество JPEG:" (по умолчанию — без изменения, оригинальное качество сохраняется)
- Кнопка **Геотегировать изображения** открывает окно предпросмотра; после подтверждения копии фото с координатами сохраняются в подпапку **geotagged/** — в каждый файл записываются EXIF GPS и XMP drone-dji теги
- Двойной клик по фотографии открывает её в полноэкранном просмотре со свойствами

### Воспроизведение
- Нажмите **▶ Воспроизвести** для анимации пролёта
- Настройте скорость выпадающим списком (x1, x2, x4)
- Нажмите **⏹ Стоп** для сброса в начало

## Поддерживаемые форматы логов

| Формат | Расширение | Описание |
|--------|------------|----------|
| DataFlash | .bin | Бинарный лог с SD-карты |
| Текстовый лог | .log | Формат ASCII |
| Телеметрия | .tlog | MavLink телеметрия |

## Зависимости

- **PySide6** (>=6.6) — Qt GUI фреймворк
- **pymavlink** (>=2.4.41) — Поддержка протокола MavLink
- **pyqtgraph** (>=0.13) — Быстрая отрисовка графиков
- **numpy** (>=1.26) — Численные вычисления
- **pandas** (>=2.1) — Обработка данных
