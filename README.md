# OMJET Log Analyzer

Продвинутое десктопное приложение для анализа полётных логов ArduPilot (.bin, .log, .tlog).

![Python](https://img.shields.io/badge/Python-3.12+-blue.svg)
![PySide6](https://img.shields.io/badge/PySide6-6.6+-green.svg)

## Возможности

- **Парсинг логов**: Поддержка форматов .bin (dataflash), .log (текст), .tlog (телеметрия)
- **Интерактивные карты**: Визуализация GPS-трека на спутниковой подложке Google (спутник/гибрид/карта/рельеф) с перетаскиваемым курсором
- **Дерево параметров с избранным и пресетами**: У каждого параметра есть звёздочка-переключатель — нажатие добавляет параметр в отдельную панель "Избранное" над общим списком (звёздочка становится жёлтой, параметр дублируется и остаётся доступным даже при пустом списке); набор избранного сохраняется на диске и восстанавливается между запусками, поле можно переименовать через правый клик → "Переименовать параметр", а весь список — очистить через "Очистить избранное"; ниже расположена панель "Пресеты" с готовыми наборами графиков (например, "AirSpeed - Ground Speed", "Battery 1 - Battery 2", "Baro - GPS Altitude" — сразу строят нужные кривые, в том числе с разбивкой по батарее)
- **Мультиграфики**: До 3 синхронизированных графиков с несколькими кривыми
- **Временная шкала**: Визуальный скрабер с отображением высоты
- **Режим воспроизведения**: Анимация пролёта лога с разной скоростью
- **Просмотр параметров**: Обзор и анализ полётных параметров
- **События**: Автоматическая расшифровка EV/ERR-сообщений (армирование, отказы подсистем и т.д.) на русском языке в таблице и в виде маркеров "!" на карте с подсказками при наведении, с переключателем видимости
- **Метки режимов и фотографий**: Цветные сегменты трека по режимам полёта, маркеры точек съёмки (CAM/TRIG) на карте со счётчиком и переключателем видимости
- **Геотегирование фотографий**: Отдельная вкладка с таблицей параметров каждого фотоснимка (координаты, высота AMSL/AGL, крен/тангаж/курс, путевая скорость, интервал и расстояние между кадрами) и экспортом в CSV — для построения ортофотоплана. Поддерживается импорт точек привязки из внешнего файла GNSS-геометок (CSV/RTKLIB .pos) со счётчиком меток и автоматическим выделением высотных выбросов; точки и фотографии можно исключать из геопривязки через контекстное меню (строка/миниатюра становится серой, точка-маркер на мини-карте тоже сереет); список фотографий переключается между видом "Список" и "Миниатюры", уже геотегированные снимки отмечаются значком-планетой с подсказкой координат/высоты; перед записью координат в EXIF показывается окно предпросмотра соответствия "файл → координаты", а сам процесс геотегирования сопровождается прогресс-баром с именем обрабатываемого файла; двойной клик по фото открывает его в полноэкранном просмотре с накладкой свойств снимка
- **Полётное задание (миссия)**: Вкладка разделена на две части — слева мини-карта с маршрутом и точками миссии (с переключателями "Центрировать" — автопанорамирование карты на выделенную точку — и "Показать весь трек" — авто-масштабирование на весь маршрут), справа таблица команд (Command, Lat, Lon, Alt, Frame, Params, Seq, Cmd ID, Description с переводом описания на русский), строки которой подсвечиваются по типу команды (взлёт/посадка VTOL — зелёным, начало фотосъёмки по дистанции — жёлтым, начало посадки — красным, облёт точки на высоте — оранжевым). При наведении на строку таблицы соответствующая точка подсвечивается на карте, и наоборот — при наведении на точку на карте подсвечивается строка в таблице. Поддерживается экспорт миссии в формате QGC WPL 110 (.waypoints)
- **Анализ миссии**: Сводная статистика полёта в две колонки. Слева — группы "Время" (старт/финиш/длительность), "Полёт" (дистанция, время работы вертикальных и маршевого моторов, время планирования), "Ветер" (средний и максимальный ветер по данным EKF, преобладающее направление — встречный/боковой/попутный), "Углы" (максимальные крен/тангаж) и "Фотосъёмка" (количество отправленных в камеры и полученных от камеры фотоимпульсов — метки CAM/TRIG, среднее время и расстояние между снимками). Справа — "Эффективность" (расход mAh на километр и на минуту, отдельно по всем моторам и только по маршевому, с цветными индикаторами по настраиваемым в Настройках порогам) и статистика по каждой батарее (расход mAh, максимальный и средний ток)
- **Ветер**: Направление и скорость ветра (по данным EKF) отображаются красным треугольником на компасе панели ориентации; участки трека на карте, где скорость ветра превышает заданный порог, подсвечиваются белым свечением; сводная статистика по ветру и преобладающее направление доступны на вкладке "Анализ миссии"
- **Отображение RC**: Визуализация каналов управления
- **Панель ориентации**: Индикаторы крена/тангажа/рыскания, скорости, высоты и ветра, с цветовой индикацией силы тока и скорости по настраиваемым порогам
- **Монитор моторов/сервоприводов**: Визуализация PWM сигналов
- **Звуковые оповещения**: Опциональный звуковой сигнал по завершении загрузки лога (включается в Настройках)
- **Офлайн-кэш тайлов карты**: Загруженные тайлы спутниковой подложки сохраняются на диск и переиспользуются без повторной загрузки из сети; размер кэша и кнопка очистки доступны в Настройках
- **Настройки**: Тема (светлая/тёмная/системная), часовой пояс, язык, конфигурация батареи (количество ячеек, LiHV), цветовые пороги силы тока/скорости и максимальный ветер для подсветки на карте, пороги расхода mAh для индикаторов на вкладке "Анализ миссии", звуковые оповещения, управление кэшем тайлов карты
- **Тёмная/светлая тема**: Переключаемое оформление

## Установка

### Из релиза (Windows)
1. Скачайте последнюю версию `OMJET_Log_Analyzer.exe` со страницы [Releases](https://github.com/andrewkena/OMJET-LOG-Analayzer/releases)
2. Запустите исполняемый файл — установка не требуется

### Из исходников
```bash
# Клонировать репозиторий
git clone https://github.com/andrewkena/OMJET-LOG-Analayzer.git
cd OMJET-LOG-Analayzer

# Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate  # Windows
# source .venv/bin/activate  # Linux/Mac

# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python main.py
```

## Использование

1. Запустите приложение
2. Нажмите **Файл → Открыть лог...** или используйте Ctrl+O
3. Выберите файл лога ArduPilot (.bin, .log или .tlog)
4. Изучайте загруженные данные:
   - Используйте **Дерево сообщений** для выбора полей на график
   - Перейдите на вкладку **Графики** для просмотра выбранных параметров
   - Откройте вкладку **Карта** для визуализации GPS-трека
   - Проверьте вкладку **События** для отметок событий полёта
   - Откройте вкладку **Полетное задание** для просмотра маршрута миссии на карте и списка команд

### Управление графиками
- Отмечайте поля в дереве сообщений, чтобы добавить их на графики
- Выпадающий список выбирает целевой график (1, 2 или 3)
- Выделяйте диапазон на графике мышкой для выбора временного диапазона
- Используйте временную шкалу внизу для навигации по полёту

### Избранное и пресеты
- Нажмите на звёздочку рядом с параметром в дереве сообщений, чтобы добавить его в панель "Избранное" (звёздочка станет жёлтой); повторное нажатие убирает параметр из избранного
- Панель "Избранное" всегда отображается над общим списком параметров, даже когда она пуста
- Панель "Пресеты" ниже списка параметров содержит готовые комбинации графиков — выберите пункт, чтобы сразу построить нужные кривые (например, сравнение воздушной и земной скорости)

### Полетное задание
- Слева на карте отображается маршрут миссии с точками
- Справа — таблица команд миссии (Command, Lat, Lon, Alt, Frame, Params, Seq, Cmd ID, Description)
- Наведите курсор на строку таблицы, чтобы выделить соответствующую точку на карте, или на точку на карте, чтобы выделить её строку в таблице
- Кнопка **Download Mission (.waypoints)** экспортирует миссию в формате QGC WPL 110 для Mission Planner/QGroundControl

### Геотегирование фотографий
- Выберите папку с фотографиями — снимки отображаются в виде миниатюр (или списка, переключатель над списком), уже содержащие GPS EXIF помечаются значком-планетой с подсказкой координат и высоты при наведении
- Импортируйте файл точек привязки (**Открыть файл геометок GNSS...**, рядом с таблицей GNSS) — поддерживаются CSV и RTKLIB .pos; точки с аномальной высотой (отклонение от средней более 10%) подсвечиваются красным
- Правый клик по точке GNSS или по фотографии — пункт "Исключить" удаляет её из геопривязки (строка/миниатюра и маркер на карте сереют), счётчик пересчитывается автоматически
- Двойной клик по фотографии открывает её в полноэкранном просмотре со свойствами (размер, вес файла, камера, дата съёмки, GPS-координаты)
- Кнопка **Геотегировать изображения** открывает окно предпросмотра соответствия "файл → координаты"; после подтверждения координаты записываются в EXIF с прогресс-баром, отображающим имя текущего файла

### Воспроизведение
- Нажмите **▶ Воспроизвести** для анимации пролёта
- Настройте скорость выпадающим списком (x1, x2, x4)
- Нажмите **⏹ Стоп** для сброса в начало

## Поддерживаемые форматы логов

| Формат | Расширение | Описание |
|--------|------------|----------|
| DataFlash | .bin | Бинарный лог с SD-карты |
| Текстовый лог | .log | Формат ASCII |
| Телеметрия | .tlog | MavLink телеметрия |

## Зависимости

- **PySide6** (>=6.6) — Qt GUI фреймворк
- **pymavlink** (>=2.4.41) — Поддержка протокола MavLink
- **pyqtgraph** (>=0.13) — Быстрая отрисовка графиков
- **numpy** (>=1.26) — Численные вычисления
- **pandas** (>=2.1) — Обработка данных
- **Pillow** (>=10.0) — Чтение/запись GPS EXIF при геотегировании фотографий
