Положите сюда картинки для инсталлятора (Inno Setup) с такими именами:

  wizard_image.bmp        - большая картинка слева (164x314 px)
  wizard_small_image.bmp  - маленький логотип справа сверху (55x55 px)

Поддерживаются BMP, JPG, PNG.
После добавления файлов сюда нужно подключить их в installer.iss (WizardImageFile / WizardSmallImageFile).
